## 1. 목적 및 배경

단일 장기 MCP 세션 안에서 연속으로 도구를 호출하는 도중 토큰 만료, Grant 회수, 주체 Epoch 증가, 서명 키 회전·폐기, 일회성 토큰 재사용, 만료 후 부모 토큰 기반 재교환이 일어나는 6대 시나리오(`G12`: `E2E-55`~`E2E-60`)를 카탈로그에 구현한다.

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/harness/catalog/g12_long_running_session.go` [신규]: `E2E-55`~`E2E-60` 6대 시나리오 구현
  - `internal/harness/catalog/catalog.go`: `AllScenarios()`에 `g12Scenarios()` 등록 (총 시나리오 54개 → 60개)
  - `internal/ui/explain.go`: `G12` 그룹 초보자 해설 추가
- **무영향**:
  - 기존 `E2E-01`~`E2E-54` 시나리오 판정 불변.

## 3. 신규 시나리오 명세 (`G12`: 장기 실행 및 토큰 수명 검증)

| ID | 시나리오명 | 세션 내 시계열 흐름 | 최종 기대 Exit | 최종 기대 감사 사유 (`Reason`) | 핵심 검증 증거 |
|:---:|---|---|---|:---:|---|
| `E2E-55` | 장기 세션 중 토큰 시간 만료 차단 | 호출 1(성공) → 가상 시계 `+15m` 전진 → 호출 2(동일 토큰) | `11` | `TOKEN_EXPIRED` | `sleep` 0초로 세션 내 2차 호출 즉시 거부 |
| `E2E-56` | 장기 세션 중 실시간 Grant 회수 및 Epoch 증가 차단 | 호출 1(성공) → `BumpEpoch` 실행 → 호출 2(미만료 토큰) | `12` | `SUBJECT_EPOCH_REVOKED` | 세션 캐시 없이 2차 호출 즉시 차단 |
| `E2E-57` | 장기 세션 중 서명 키 회전(유지) 후 폐기(`retired`) 즉시 차단 | `key-v1` 호출 1(성공) → `RotateKey`(`verify-only` 유지, 호출 2 성공) → `RevokeKey`(`key-v1` 폐기) → 호출 3 | `11` | `TOKEN_KEY_RETIRED` | 무중단 키 회전 중 허용 및 폐기 직후 즉시 차단 |
| `E2E-58` | 장기 세션 내 일회성(`one_time`) 토큰 2회차 재사용 차단 | `one_time: true` 토큰으로 호출 1(성공) → 동일 세션 내 호출 2 | `11` | `TOKEN_REPLAY_DETECTED` | Replay 원장에 의해 2차 호출 즉시 차단 |
| `E2E-59` | 자식 토큰 만료 후 유효한 부모 토큰 기반 재교환(Re-Exchange) 세션 재개 | 자식 토큰 1 만료(거부) → 부모 토큰으로 자식 토큰 2 재교환 → 호출 재시도 | `0` | `AUTHORIZED` | Refresh Token 없이 재교환으로 장기 세션 안전 지속 증명 |
| `E2E-60` | 부모 토큰 만료 후 재교환 시도 거부 (수명 상한 우회 차단) | 가상 시계를 부모 `exp` 이후로 전진 → 자식 토큰 재교환 요청 | `11` | `TOKEN_EXPIRED` | 부모 수명을 넘어서는 세션 연장 원천 차단 |
