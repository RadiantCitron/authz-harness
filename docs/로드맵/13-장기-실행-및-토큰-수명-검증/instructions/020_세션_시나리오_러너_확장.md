## 1. 목적 및 배경

기존 [`g8_mcp_adapter.go`](../../../../internal/harness/catalog/g8_mcp_adapter.go)의 `executeMCPCall`은 `bytes.NewReader`에 요청 1줄만 넣어 `server.Serve(ctx)`가 1회 응답 후 즉시 `io.EOF`로 종료되는 단발성 헬퍼다.
본 단계에서는 **단일 `mcp.Server` 인스턴스를 `io.Pipe()` 스트림으로 열어 둔 채** `Step 1(호출 허용) → Step 2(시각 전진 / 권한 회수 / 키 회전·폐기) → Step 3(동일 세션 내 재호출 거부)`를 연속 실행할 수 있는 대화형 세션 드라이버(`SessionDriver`)를 구현한다.

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/mcp/executor.go`: `SubprocessExecutor`에 선택적 시계 오프셋 공급 함수(`WithClockOffsetProvider(fn func() time.Duration)`)를 추가하여 `ExecuteTool` 호출 시 현재 가상 시계 오프셋을 `SubagentRequest.ClockOffsetSeconds`에 자동 주입
  - `internal/harness/catalog/session_helper.go` [신규]: `io.Pipe()` 기반 양방향 스트림 위에서 단일 `mcp.Server` 고루틴을 유지하며 다중 `tools/call`과 상태 변이(`AdvanceClock`, `RevokeGrant`, `BumpEpoch`, `RotateKey`, `RevokeKey`)를 수행하는 `SessionDriver` 구현
  - `internal/harness/catalog/session_helper_test.go` [신규]: 단일 세션 내 연속 호출 및 시각 전진·권한 회수 단위 테스트
- **무영향**:
  - 기존 `executeMCPCall` 및 `E2E-01`~`E2E-54` 시나리오의 동작은 전혀 변경하지 않는다.

## 3. 세부 명세

### 3.1 `io.Pipe()` 기반 지속형 MCP 세션 구조 (`internal/harness/catalog/session_helper.go`)
1. **스트림 연결 (조기 `io.EOF` 및 데이터 레이스 방지)**:
   - `clientInR, clientInW := io.Pipe()` 및 `serverOutR, serverOutW := io.Pipe()`를 생성한다.
   - 백그라운드 고루틴에서 `server.Serve(ctx)`를 실행(`in = clientInR`, `out = serverOutW`)하고, `Close()` 시 `clientInW.Close()`를 호출하여 서버 루프를 정상 종료(`io.EOF`)시킨다.
   - `CallTool(toolName string, args map[string]any, tokenVal string)`은 `clientInW`에 JSON-RPC 1줄을 쓰고 `bufio.Reader`(`serverOutR`)에서 응답 1줄을 읽어 종료 코드와 `JSONRPCResponse`를 반환한다 (`inproc` 모드로 실행될 때에도 `inProcSpawnerBridge`가 `req.ClockOffsetSeconds`를 `pep.Request.ClockOffset`으로 전달하도록 연동한다).
2. **시각 전진 (`AdvanceClock(d time.Duration)`)**:
   - `SessionDriver` 내부의 누적 `clockOffset`을 `+d`만큼 증가시키고 샌드박스의 가상 시계도 동기화한다.
   - 이후 `CallTool` 호출 시 `SubprocessExecutor`가 누적 `clockOffset`을 `SubagentRequest.ClockOffsetSeconds`에 담아 서브프로세스 워커로 전달한다.

## 4. 인수 테스트 시나리오

| ID | 입력 | 기대 결과 |
|:---:|---|---|
| **TC-020-01** | 한 MCP 세션에서 세션 토큰(`MaxCalls: 5`, TTL 5분)으로 `CallTool`(1차) → `AdvanceClock(+6m)` → 동일 토큰 `CallTool`(2차) | 1차 `ExitSuccess(0)`, 2차 `ExitTokenInvalid(11)` (`[TOKEN_EXPIRED]`) |
| **TC-020-02** | 한 MCP 세션에서 세션 토큰으로 `CallTool`(1차) → `RevokeGrant` → 동일 토큰 `CallTool`(2차) | 1차 `ExitSuccess(0)`, 2차 `ExitAuthzDenied(12)` (`[GRANT_REVOKED]`) |
| **TC-020-03** | `SessionDriver.Close()` 호출 | 파이프 닫힘과 함께 백그라운드 `server.Serve` 고루틴이 누수 없이 즉시 종료됨 |
