# [구현지시서 060] 전체 회귀 검증, 재교환 충분성 결론 기록 및 마감

> **문서 상태**: `Draft`
> **상위 대시보드**: [13번 README.md](../README.md) | [ROADMAP.md](../ROADMAP.md)
> **선행 조건**: [050_g12_e2e_시나리오.md](050_g12_e2e_시나리오.md) 완료

## 1. 목적 및 배경

13번 로드맵의 장기 세션 검증 시나리오를 포함한 총 60대 시나리오(`E2E-01`~`E2E-60`)의 전체 회귀를 수행하고, [ADR 0003](../../../adr/0003-차기-로드맵-범위-개정-비목표-조건부-해제.md) C-4에서 요구한 **"Refresh Token 없이 부모 토큰 기반 재교환만으로 장기 에이전트 세션 운용에 충분한가"**에 대한 검증 결론을 대시보드 결정 표에 기록한다.

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - [최상위 README.md](../../../../README.md), [MASTER_ROADMAP.md](../../MASTER_ROADMAP.md), [전체 로드맵 색인](../../README.md), [13번 대시보드 README.md](../README.md): 총 시나리오 수(60개, `G1`~`G12`), TOCTOU 창 정의 및 재교환 검증 결론 동기화

  - 프로덕션 코드 변경 없음.

## 3. 세부 명세

1. `go test -race ./...` 전체 실행 및 통과 확인.
2. `authz-harness run --scenario all`로 60개 시나리오 전수 `PASS` 확인.
3. `authz-harness audit verify`로 해시 체인 `VALID` 확인.
4. [13번 대시보드 README.md](../README.md) §4 결정 표에 재교환 충분성 평가 결과(부모 세션 수명 안에서는 재교환으로 충분하며 Refresh Token 비목표 유지 확정)를 기록하고 로드맵을 `Done`으로 마감한다.
