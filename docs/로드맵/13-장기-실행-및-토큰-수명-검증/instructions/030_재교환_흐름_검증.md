## 1. 목적 및 배경

1. **부모·자식 주체별 `Epoch` 분리 ([011번 보고서](../../../보고서/011-권한관리_본질_코어파이프라인_안티패턴_및_분산적응형_기본구조_전문가진단_보고서.md) 제안 1)**:
   - 현재 [`internal/authn/exchange/service.go:146`](../../../../internal/authn/exchange/service.go)은 자식 토큰을 발급할 때 자식의 `Epoch`가 아닌 **부모의 `Epoch`(`parentClaims.Epoch`)를 자식 토큰의 `Epoch` 필드에 덮어쓰는 결함**이 있다. 이로 인해 부모(`lead-01`, `Epoch: 2`)와 자식(`worker-01`, `Epoch: 1`)의 Epoch가 서로 다를 경우 정상 위임 토큰이 PDP에서 `2 != 1`로 거부된다.
   - 이를 해결하기 위해 [`internal/domain/token.go`](../../../../internal/domain/token.go)의 `ActorClaim`(`act`)에 `Epoch domain.Epoch` (`json:"epoch,omitempty"`) 필드를 추가하여 부모의 `Epoch`는 `childActor.Epoch`에 정확히 보존하고, 자식 토큰 본체의 `Epoch`에는 자식 주체(`ChildSubject`)의 Epoch(기본값 `1` 또는 `ExchangeRequest.ChildEpoch` / `EpochProvider` 조회값)를 부여한다.
2. **재교환(Re-Exchange) 단조 축소 검증**:
   - Refresh Token 없이, 만료된 단기 자식 토큰(`T_child_1`)을 아직 유효한 부모 토큰(`T_parent`)으로 재교환(`T_child_2`)할 때 수명(`exp`), 권한(`scope`), 잔여 예산(`budget`) 단조 축소가 유지되고 부모 만료 후에는 재교환이 차단됨을 증명한다.

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/domain/token.go`: `ActorClaim`에 `Epoch Epoch` (`json:"epoch,omitempty"`) 필드 추가
  - `internal/authn/exchange/service.go`:
    - `ExchangeRequest`에 선택적 `ChildEpoch domain.Epoch` 추가 (미지정 시 등록된 `EpochProvider` 조회 또는 기본값 `1` 적용)
    - `childActor := &domain.ActorClaim{Subject: parentClaims.Subject, JWTID: parentClaims.JWTID, Epoch: parentClaims.Epoch, Actor: parentClaims.Actor}`로 상위자의 `Epoch`를 `act` 체인에 보존
  - `internal/authn/exchange/reexchange_test.go` [신규]: 부모(`Epoch 2`) → 자식(`Epoch 1`) 교차 Epoch 위임 정상 동작 테스트 및 시간 경과에 따른 재교환 성공·잔여 수명 초과 거부·부모 만료 후 재교환 거부 Table-Driven 테스트
- **무영향**:
  - 부모와 자식이 모두 `Epoch: 1`인 기존 모든 시나리오는 100% 동일하게 동작한다.

## 3. 인수 테스트 시나리오

| ID | 입력 | 기대 결과 |
|:---:|---|---|
| **TC-030-01** | 부모(`lead-01`, `Epoch: 2`)가 자식(`worker-01`, `Epoch: 1`)용 토큰 교환 후 PDP 판정 | 자식 토큰 `Claims.Epoch == 1`, `Claims.Actor.Epoch == 2`로 정상 발급 및 PDP `ALLOW` 통과 |
| **TC-030-02** | 자식 토큰 만료 후 유효한 부모 토큰으로 잔여 TTL 이내 재교환 | 새 `jti`를 가진 자식 토큰 2 발급 성공, 감사에 `token.exchanged` 기록 |
| **TC-030-03** | 부모 잔여 수명(2분)보다 긴 TTL(5분)로 재교환 요청 | `ReasonDelegationTTLExceeded`(`12`) 거부 |
| **TC-030-04** | 만료된 부모 토큰으로 재교환 요청 또는 자식 토큰 셀프 연장 시도 | `ReasonTokenExpired`(`11`) / `ReasonDelegationSelfLoop`(`12`) 거부 |
