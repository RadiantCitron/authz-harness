## 1. 목적 및 배경

장기 실행되는 에이전트 세션에서 시간 경과에 따른 토큰 만료·권한 회수·키 폐기를 `time.Sleep` 없이 결정론적으로 재현하려면, 부모 프로세스(MCP 어댑터 또는 오케스트레이터)의 가상 시계 오프셋(`ClockOffset`)이 호출마다 기동되는 자식 서브프로세스 워커의 [`pep.Request.ClockOffset`](../../../../internal/authz/pep/gateway.go)까지 정확히 전달되어야 한다.
또한 단일 세션 내에서 동일 토큰으로 여러 번 호출할 때(예: 만료 전 허용 → 만료 후 거부), 1회성 토큰(`Budget == nil`)과 다회성 세션 토큰(`Budget != nil`, 로드맵 12)의 역할을 명확히 구분해야 Gate 1 `ReplayLedger` 오차단을 피할 수 있다.

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/subagent/protocol.go`: `SubagentRequest`에 선택적 `ClockOffsetSeconds int64` (`json:"clock_offset_sec,omitempty"`) 필드 추가
  - `internal/subagent/worker.go`: `Execute` 메서드에서 `pep.Request` 조립 시 `ClockOffset: time.Duration(req.ClockOffsetSeconds) * time.Second`를 전달하도록 배선 (현재 `pep.Request`에 `ClockOffset` 필드가 이미 존재하나 `worker.go` 38행에서 연결이 누락되어 있던 지점을 완성)
  - `internal/authz/pep/gateway.go`: `req.ClockOffset != 0`일 때 Gate 1(`VerifyToken`)뿐 아니라 PEP/예산 만료 판정 시계에도 동일한 `OffsetClock`이 적용되도록 일원화
  - `internal/subagent/worker_clock_test.go` [신규]: `time.Sleep` 없이 `ClockOffsetSeconds` 주입만으로 자식 워커에서 토큰 만료(`TOKEN_EXPIRED`) 및 미래 토큰(`TOKEN_NOT_YET_VALID`)이 즉시 판정되는지 검증하는 단위 테스트
- **무영향**:
  - `ClockOffsetSeconds == 0`인 기본 요청은 기존과 동일하게 동작하므로 기존 `E2E-01`~`E2E-54` 시나리오에 영향을 주지 않는다.

## 3. 세부 명세

1. **호출 단위 재검증 원칙 (Zero Session Trust Cache)**:
   - [`internal/mcp/server.go`](../../../../internal/mcp/server.go) 및 [`internal/mcp/executor.go`](../../../../internal/mcp/executor.go)는 이전 `tools/call`에서 성공한 토큰이나 PDP 판정 결과를 메모리에 캐시하지 않는다.
   - 모든 `tools/call`은 독립 서브프로세스를 통해 Gate 1(JWKS/Replay/TTL)과 Gate 2(PDP Grant/Epoch/Budget)를 매번 새로 평가한다.
2. **세션 토큰(다회성) vs 일회성 토큰(`one_time`) 구분 규약**:
   - 한 세션 내에서 동일 토큰 `T1`으로 `1차 호출(성공) → 상태 변화(시각 전진 / Grant 회수 / 키 회전·폐기) → 2차 호출`을 수행하는 시나리오(`E2E-55`~`E2E-57`)에서는 `T1`에 세션 예산(`Budget: &domain.Budget{MaxCalls: 10}`)을 부여하여 Gate 1 일회성 `ReplayLedger` 소비 대신 세션 내 다회 호출이 허용되게 한다.
   - 반대로 일회성 토큰(`Budget == nil`)을 동일 세션 내 2회 재사용할 때 즉시 차단됨을 증명하는 시나리오(`E2E-58`)는 `ReplayLedger`가 2차 호출을 `TOKEN_REPLAY_DETECTED(11)`로 거부함을 검증한다.
3. **서브프로세스 시계 오프셋 전달 (`internal/subagent/worker.go`)**:
   - `SubagentRequest.ClockOffsetSeconds`를 `time.Duration(req.ClockOffsetSeconds) * time.Second`로 변환해 `pepReq.ClockOffset`에 주입한다.
