## 1. 목적 및 배경

향후 사용자가 실제 멀티·분산 에이전트 프로그램을 개발할 때, 본 프로젝트에서 검증된 코어 패키지(`domain`, `authn`, `authz`, `audit`, `observe`, `confine`, `mcp`)를 **공통 에이전트 모듈(Agent SDK / Base Runtime)**로 감싸서 이식하는 구체적인 설계 패턴과 어댑터 교체 방법을 `docs/교보재/04-자체에이전트_모듈_권한감사_배선_이식가이드.md`로 작성한다.

---

## 2. 필수 포함 내용

1. **단일 머신 다중 에이전트 이식 패턴**: 오케스트레이터(`SubprocessSpawner` + `ExchangeService`)와 워커(`SubagentWorker` + `pep.Gateway`) 결합 방법
2. **원격 분산 에이전트 이식 패턴**: `audit.Writer`, `domain.SnapshotProvider`, `observe.Observer` 인터페이스의 원격 어댑터 구현 패턴
3. **신규 도구 추가 시 체크리스트**: `pep.ToolHandler` 구현 및 스코프 등록만으로 안전하게 도구를 확장하는 3단계 절차
