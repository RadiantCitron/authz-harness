## 1. 목적

자식 프로세스를 운영체제 차원에서 가두는 일, 판정과 별개로 운영 로그를 내는 일, 감사 파일 자체를 위변조로부터 지키는 일을 다룬다. 이 셋은 「감사가 왜 믿을 만한가」라는 하나의 질문으로 묶인다(원안 `030` SESE·3-Zone 해설의 질문을 이어받는다). 파일 이름은 `docs/설명서/006-OS격리_관측성과_감사체크포인트.md`로 한다.

1. **OS 격리**: `confinement.Confiner` 포트, macOS seatbelt·Linux Landlock 어댑터, 신뢰 런처, 격리 필수 모드에서 적용 불가 시 `CONFINEMENT_UNAVAILABLE`(16), 포트 단위 허용(`AllowConnectPorts`). 자원 상한(`orchestrator.Limits`: `Timeout`·`WaitDelay`·`MaxOutputBytes`)도 여기서 다룬다. CPU·메모리 상한은 지금 없다.
2. **관측성 삼분**: `stdout` / `stderr`(`observe.Observer` 4메서드, `slogadapter`, `WrapSafe`의 panic 차단) / `audit.jsonl`. 관측이 판정에 영향을 주지 않는 이유.
3. **감사 무결성**: 스키마 v2(`arg_hash`·`result_hash`, `domain.DataDigest`), Zone A Ed25519 서명 체크포인트([checkpoint.go](../../../../internal/audit/checkpoint/checkpoint.go))가 해시 체인만으로는 못 막는 무엇(끝부분 절단·파일 교체)을 막는가, `audit tree`.

## 2. 사실대로 써야 하는 것 (E18-05, 결정 D-3)

`pep.WithBeforeIOHook`을 다룰 때 다음을 그대로 적는다(코드는 고치지 않는다. 별도 계획에서 다룬다).

- 훅은 이름과 달리 I/O 직전이 아니라 **관문 전체 실행 전**에 돈다([decorator.go](../../../../internal/authz/pep/decorator.go) `:15-26`).
- 결함 주입 스위치 `InjectRevokeBeforeIO`는 프로덕션 요청 타입 `pep.Request`에 있고, CLI 서브에이전트는 이 훅을 항상 장착한다([subagent.go](../../../../internal/cli/subagent.go) `:108`).
- 훅이 실패하면 `finalize`·감사 없이 `HOOK_ERROR`(종료 코드 16)로 나간다. 이 출구는 3부 「이상이 생기면」 표와 5부 ① 「지금은 없는 것」에 적는다.
