## 1. 목적

[설명서](../../../설명서/README.md) 001~004편은 기준 커밋 `b5049c5`(2026-11-02)에 머물러 있다. 그 뒤 `cmd/`·`internal/`을 바꾼 커밋이 45개 있다(10~17번 로드맵). 설명서 README의 「갱신 규칙」에 따라 네 편의 서술을 현재 코드(기준 커밋 `34ad499`)에 맞춘다. 이 단계는 **이미 있는 편에서 사실과 달라진 서술을 고치는 일**만 한다. 새 주제를 자세히 쓰는 일은 `020`~`040`이 맡는다.

## 2. 착수 전 대조 (이미 확인된 불일치)

| 편 | 현재 서술 | 실제 코드 |
|---|---|---|
| 001 | Gate 0의 `Action`은 `file:read`/`file:write`만 받는다 (5부 ① 185행) | `net:fetch`·`exec:run`까지 4종 ([gateway.go](../../../../internal/authz/pep/gateway.go) `:234`, `:341`, `:433`) |
| 001 | Gate 2c는 작업 폴더 검사, Stage 5는 파일 읽기·쓰기만 한다 (그림 129~131행) | Gate 2c·Stage 5가 도구 종류별로 갈라지고, Gate 2c와 Stage 4 사이에 `StageApproval`·`StageBudget`이 있다 ([gateway.go](../../../../internal/authz/pep/gateway.go) `:39-42`) |
| 001 | 「운영체제 커널 수준 격리는 지금은 없다」 (188행) | [internal/confinement/](../../../../internal/confinement/port.go) (Landlock·seatbelt 어댑터)가 있다 |
| 001 | 정책 결정은 allow/deny 2값 | allow/deny/ask 3값 (15번) |
| 004 | `tools/list`는 `file_read`·`file_write`만 낸다 (167·168행) | `net_fetch`·`exec_run`도 있다 ([mcp/protocol.go](../../../../internal/mcp/protocol.go) `:17-20`) |
| 002 | 교환 시 `ActorClaim` 중첩만 설명 | `ActorClaim.Epoch`·`ChildEpoch`, PDP의 `act` 사슬 비교 (13번) |
| 003 | 감사 레코드 필드·검증 | 스키마 v2(`arg_hash`·`result_hash`), Zone A 서명 체크포인트, `audit tree` (14번) |

위 표는 출발점일 뿐이다. 각 편의 모든 서술을 코드와 다시 대조하고, 표에 없는 불일치도 찾아 고친다.

## 3. 작업 규칙

1. 편마다 머리의 **기준일·기준 커밋**을 갱신한다(`git log -1 --format=%h -- cmd internal`).
2. 새 개념(승인·예산·도구 가드·OS 격리·관측성·체크포인트)은 그 편의 흐름에 필요한 만큼만 한두 문단으로 요약한다. 자세한 설명은 해당 편(`005`/`006`)으로 넘기는 링크를 둔다(설명서 README 「편이 겹치면 한 곳에만 자세히」). 링크 대상 편이 아직 없으면 링크 없이 요약만 쓰고, `020`·`030`에서 링크를 단다.
3. 5부 ② 코드 정본 색인을 먼저 고치고, 본문 귀띔은 같은 이름·번호로 맞춘다.
4. 과거 서술(「○번 로드맵에서 바뀌었다」)은 쓰지 않는다. 단, 5부 ② 항목 끝의 `구현: P13-020 (abc1234)` 표기는 허용된다.
5. 편마다 단독 커밋한다(4커밋).

## 4. 인수 기준 (편마다)

| 번호 | 기준 | 판정 방법 |
|:---:|---|---|
| A-1 | 본문·5부 ②에 인용한 파일·타입·함수가 HEAD에 모두 있다 | 인용 식별자마다 `grep -rn "<이름>" internal cmd`로 확인하고 결과를 5부 ③에 남긴다 |
| A-2 | 「지금은 없다」로 적은 항목이 실제로 없다 | 항목마다 코드 검색 결과를 5부 ③에 남긴다 |
| A-3 | 동작·순서·소유자·시점 4축 대조표(5부 ③)가 갱신되었고, 확인하지 못한 것은 「미확인」이다 | 5부 ③ 표 |
| A-4 | 설명서 README 「쓴 뒤 네 가지 점검」 ①~④를 통과한다 | 점검 결과를 커밋 메시지 본문에 한 줄씩 적는다 |
| A-5 | 모든 상대경로 링크 대상이 실재한다 | 아래 링크 검사 명령 |
| A-6 | `.go` 파일 변경 0건 | `git diff --stat -- '*.go'` 빈 출력 |

```bash
# 링크 검사 (편 파일에서 실행 위치: docs/설명서/)
f=001-전체요청여정과_5단계관문.md
grep -oE '\]\([^)#]+' "$f" | sed 's/](//' | sort -u | while read p; do [ -e "$p" ] || echo "BROKEN: $p"; done
```
