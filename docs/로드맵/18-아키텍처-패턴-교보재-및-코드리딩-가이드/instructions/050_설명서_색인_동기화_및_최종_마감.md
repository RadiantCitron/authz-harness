## 1. 목적

001~007편 전체의 기준 커밋과 상호 링크를 마지막으로 맞추고, 최상위 [README.md](../../../../README.md), [전체 로드맵 색인](../../README.md), [MASTER_ROADMAP.md](../../MASTER_ROADMAP.md)에서 설명서로 가는 길을 정리한 뒤 18번을 마감한다.

## 2. 작업

1. 001~007편 머리의 기준 커밋이 모두 `git log -1 --format=%h -- cmd internal`과 같은지 확인한다. 다르면 그 사이 코드 변경을 대조해 고친다.
2. 편 사이 「겹치는 주제」 줄과 요약→상세 링크가 양방향으로 맞는지 확인한다.
3. 최상위 README에 설명서 목차 링크가 있는지 확인하고, 없으면 추가한다.
4. 18번 README·로드맵 색인·MASTER_ROADMAP의 18번 상태를 `Done`으로 갱신한다.
