## 1. 목적 및 배경

사용자가 오랜 시간이 지난 뒤에도 전체 코드베이스를 가장 이해하기 쉬운 순서대로 따라가며 분석할 수 있도록, **5단계 코드리딩 추천 동선**과 **4계층(Delivery/Composition → Application Orchestration → Pure Domain/Policy → Driven Adapters) 의존성 역전(DIP) 해부서**를 `docs/교보재/01-코드리딩_동선_및_4계층_의존성역전_해부.md`로 작성한다.

---

## 2. 필수 포함 내용

1. **5단계 추천 코드리딩 순서**:
   - Step 1: 순수 도메인 모델과 에러 규약 (`internal/domain/`)
   - Step 2: 순수 결정 코어 (`internal/authz/pdp/`, `internal/authn/exchange/validator.go`)
   - Step 3: 단일 입출구(SESE) 집행 파이프라인 (`internal/authz/pep/gateway.go`)
   - Step 4: 원자적 저장소와 어댑터 (`internal/storage/atomic.go`, `internal/audit/`, `internal/observe/`, `internal/jail/`, `internal/confine/`)
   - Step 5: 프로세스 경계 및 단일 합성 루트 (`internal/orchestrator/`, `internal/subagent/`, `internal/mcp/`, `internal/app/builder.go`)
2. **의존성 역전(DIP) 실물 코드 대조**:
   - `pdp` ↔ `domain.SnapshotProvider` ↔ `pip`의 인터페이스 소유권과 import 화살표 역전 원리 해설.
