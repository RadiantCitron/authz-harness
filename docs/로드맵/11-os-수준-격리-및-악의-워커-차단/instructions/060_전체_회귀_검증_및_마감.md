## 1. 목적 및 배경

11번 로드맵의 OS 수준 커널 격리 도입이 기존 44대 시나리오(`E2E-01`~`E2E-44`)를 깨뜨리지 않았음을 전체 회귀로 검증하고, 플랫폼별(macOS vs Linux) 커널 격리 보증 범위와 도구 상태를 문서에 정직하게 동기화한다.

- **변경**:

## 3. 세부 명세

1. `go test -race ./...` 및 `go test -race -tags testworker ./...` 전체 실행 및 통과 확인.
2. `authz-harness run --scenario all`로 `E2E-01`~`E2E-49` 49개 시나리오 전수 `PASS` 및 `audit verify` `VALID` 확인.
3. 플랫폼 보증 표 문서화:
   - macOS(`darwin`): Seatbelt(`sandbox-exec`) 커널 프로파일 실증 완료 (`PASS`, deprecated 도구 상태 및 `Confiner` 포트 교체 가능 구조 명시)
   - Linux(`linux`): Landlock 어댑터 코드 및 교차 컴파일 검증 여부, 실제 Linux 커널 실행 검증 상태 정직하게 표기
