## 1. 목적 및 배경

11번 로드맵의 커널 격리 도입이 기존 44대 시나리오(`E2E-01`~`E2E-44`)를 깨뜨리지 않았음을 전체 회귀로 검증하고, 플랫폼별 보증 범위를 문서에 정직하게 기록한다.

하네스는 프로덕션 바이너리를 **태그 없이** 빌드해 시험한다(ADR 0003 C-7). 회귀는 한 벌(`go test -race ./...`)이며 별도 태그 회귀는 없다.

## 3. 세부 명세

1. `go test -race ./...` 전체 실행 및 통과 확인.
2. `authz-harness run --scenario all`로 49개 시나리오 실행. 격리 가능 환경에서는 49/49 `PASS`, 격리 불가 환경에서는 `PASS` 44 + `Skipped` 5를 기록하고 G10 미검증을 명시한다(`Done` 판정은 격리 가능 환경의 49/49 기준).
3. `authz-harness audit verify` → `VALID`.
4. 플랫폼 보증 표:

   | 플랫폼 | 어댑터 | 보증 내용 | 검증 상태 |
   |---|---|---|---|
   | macOS | `darwin-seatbelt` (`sandbox-exec`, deprecated 도구 — 포트 뒤 교체 가능) | `ProtectedRoot` 목록 외 읽기 거부, `WritePaths` 외 쓰기 거부, 네트워크 거부, 자손 상속, `chmod` 우회 불가 | 실행 결과 기록(PASS / 중첩 샌드박스로 Skipped) |
   | Linux | `linux-landlock` (+ `confine-exec` 런처) | 같은 최소 보장 계약, 네트워크는 ABI v4+에서만 (미만이면 필수 모드 거부) | 교차 컴파일 PASS / 런타임 검증 여부 정직 기록 |
   | 기타 | `none` | 보장 없음, 필수 모드는 항상 `16` | 단위 테스트 |
