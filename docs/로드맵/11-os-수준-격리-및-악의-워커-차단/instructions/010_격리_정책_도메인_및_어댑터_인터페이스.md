## 1. 목적 및 배경

플랫폼 어댑터를 만들기 전에, **모든 어댑터가 같은 의미로 집행할 수 있는** 격리 정책(`Policy`)과 어댑터 포트(`Confiner`)를 먼저 고정한다. 그리고 코어 패키지가 특정 OS 샌드박스 구현을 import하지 못하도록 AST 가드레일(`TC-110-01`)을 만든다.

정책은 **허용 목록**만으로 표현한다. Linux Landlock은 허용 규칙만 표현할 수 있어서 거부 목록(`DenyPaths`)이나 "쓰기 가능한 디렉터리 아래의 읽기 전용 파일"(`ReadOnlyPaths`)을 집행할 수 없기 때문이다(020번 보고서 L-4). 허용 목록은 AGENTS.md의 Deny-by-Default 원칙과도 같다.

`grants_state.json`을 읽기 전용으로 보호하지 않는다. 워커는 이 파일을 실제로 갱신하며([`cli/subagent.go`](../../../../internal/cli/subagent.go) 103행), [`storage/atomic.go`](../../../../internal/storage/atomic.go)는 같은 디렉터리에 `.lock`·임시 파일을 만들고 `rename`한다. Zone B의 무결성은 PDP·Epoch가 담당한다(L-5). 격리가 증명할 대상은 **Zone A(서명 개인키)와 샌드박스 밖**이다.

## 3. 세부 명세

### 3.1 `confinement.Policy` (`policy.go`)

```go
type Policy struct {
    Require       bool     // true: 격리를 적용할 수 없으면 스폰 거부(16)
    ProtectedRoot string   // 이 아래는 목록에 없는 한 읽기·쓰기 모두 거부
    ReadPaths     []string // ProtectedRoot 안에서 읽기만 허용할 경로
    WritePaths    []string // 읽기·쓰기를 허용할 경로 (ProtectedRoot 안팎 무관, 이 밖의 쓰기는 전부 거부)
    AllowNetwork  bool     // 기본 false: 소켓 연결·바인드 거부
}
```

1. **최소 보장 계약** (모든 어댑터가 지켜야 하는 것):
   - `ProtectedRoot` 아래에서 `ReadPaths`·`WritePaths`에 속하지 않는 경로는 **읽을 수 없다**.
   - `WritePaths` 밖에는 **쓸 수 없다**(`/dev/null` 같은 장치 파일 예외는 어댑터가 정한다).
   - `AllowNetwork == false`이면 네트워크 연결·바인드가 **실패한다**.
   - 어댑터는 이보다 **엄격할 수는 있으나 느슨할 수는 없다**(예: Landlock은 `ProtectedRoot` 밖 읽기도 시스템 경로로 제한한다).
2. `Validate() error`:
   - `ProtectedRoot`가 비어 있거나, 어느 경로든 `filepath.IsAbs`가 거짓이면 `domain.NewError(domain.ReasonInvalidArguments, "confinement_policy", ..., nil)`(`14`).
   - `ReadPaths`의 각 경로는 `ProtectedRoot` 아래여야 한다(밖이면 의미가 없으므로 `14`).
3. `WorkerPolicy(root, workspaceDir, zoneBDir, auditPath string) Policy`:
   - `ProtectedRoot = root`, `WritePaths = [workspaceDir, zoneBDir, auditPath, auditPath + ".lock"]`, `ReadPaths = nil`, `AllowNetwork = false`, `Require = true`.
   - `zone_a`는 어느 목록에도 넣지 않는다. 이 함수는 경로 문자열만 받으며 `harness`를 import하지 않는다.

### 3.2 `Confiner` 포트와 `NoopConfiner` (`port.go`)

```go
type Confiner interface {
    Name() string     // "none", "darwin-seatbelt", "linux-landlock"
    Available() bool  // 현재 실행 환경에서 실제로 적용 가능한가
    Prepare(cmd *exec.Cmd, p Policy) error
}
```

1. `Prepare` 계약:
   - `p.Validate()`를 먼저 호출하고 실패를 그대로 반환한다.
   - 성공하면 `cmd.Path`·`cmd.Args`만 래퍼(`sandbox-exec`, `confine-exec`)로 바꾼다. `cmd.Env`·`Stdin`·`Stdout`·`SysProcAttr`는 건드리지 않는다.
   - 래퍼는 **반드시 `exec`로 대상 바이너리로 바뀌어야 한다**(fork 금지). 그래야 PID·프로세스 그룹이 같아서 10번의 그룹 종료와 `classifyExit`가 그대로 작동한다.
   - 적용할 수 없으면 `domain.NewError(domain.ReasonConfinementUnavailable, "confinement", ..., nil)`(`16`)을 반환한다.
   - **정리 콜백은 두지 않는다.** 어댑터는 파일시스템이나 부모 상태를 바꾸지 않는다(교정 전의 `chmod` 잠금·복원은 같은 UID가 되돌릴 수 있는 플라시보라 폐기, L-1).
2. `NoopConfiner`: `Name() == "none"`, `Available() == false`. `Prepare`는 `p.Require`이면 `16`을 반환하고, 아니면 `cmd`를 바꾸지 않고 `nil`을 반환한다(대조군 전용).

### 3.3 AST 가드레일 (`TC-110-01`)

- `internal/domain`, `internal/authn/...`, `internal/authz/...`, `internal/jail`, `internal/audit`의 프로덕션 파일이 `"authz-harness/internal/confinement"`를 import하면 실패한다. 기존 `TestArchitectureGuardrails`의 하위 테스트로 추가한다.
