## 1. 목적 및 배경

서브프로세스 워커에 OS 커널 수준의 격리 프로파일을 씌우기 전에, 플랫폼 비의존적인 격리 정책(`ConfinementPolicy`)과 어댑터 포트(`Confiner`)를 정의하고, 코어 패키지가 특정 OS 샌드박스 구현을 직접 import하지 못하도록 AST 가드레일(`TC-110-01`)을 먼저 구축한다.
또한 격리 켬/끔 대조군 실험에 사용할 `none` 어댑터를 함께 정의하되, 격리 필수 모드(`RequireConfinement: true`)에서는 `none` 어댑터가 거부되도록 계약을 고정한다.

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/domain/constants.go`, `internal/domain/error.go`: `ReasonConfinementUnavailable`, `ReasonConfinementViolation` 상수 및 `ExitCodeForReason` 매핑 추가
  - `internal/confinement/policy.go` [신규]: `Policy` 구조체(허용 읽기 경로, 허용 쓰기 경로, 거부 경로, 네트워크 허용 여부, 필수 여부) 및 유효성 검증 구현
  - `internal/confinement/port.go` [신규]: `Confiner` 인터페이스(`Name()`, `Available()`, `WrapCommand(cmd *exec.Cmd, policy Policy) error`) 및 대조군용 `NoopConfiner` 구현
  - `internal/confinement/policy_test.go` [신규]: 정책 정규화·검증 및 `NoopConfiner` 계약 단위 테스트
  - `internal/harness/architecture_test.go`: 코어 패키지(`domain`, `authn`, `authz`, `jail`, `audit`)가 `internal/confinement`의 플랫폼 하위 패키지를 import하지 못하게 강제하는 `TC-110-01` 추가
- **무영향**:
  - 아직 `orchestrator.SubprocessSpawner`에 연결하지 않으므로 기존 서브프로세스 실행 동작은 변하지 않는다.

## 3. 세부 명세

1. **`confinement.Policy` 구조체**:
   - `RequireConfinement bool`: `true`일 때 커널 격리 어댑터를 사용할 수 없으면 즉시 스폰을 거부(Fail-Closed)한다.
   - `AllowReadPaths []string`: 워커 실행에 필요한 읽기 전용 절대경로 목록(바이너리, Zone B 공개 키/상태 파일 등).
   - `AllowWritePaths []string`: 워커가 기록할 수 있는 절대경로 목록(Workspace 디렉터리, 감사 로그 및 락 파일, Replay 원장 및 락 파일).
   - `DenyPaths []string`: 상위 경로가 열려 있더라도 명시적으로 차단할 절대경로 목록(특히 **Zone A 개인키 디렉터리**).
   - `AllowNetwork bool`: 기본 `false` (모든 네트워크 소켓 생성 및 외부 연결 차단).
2. **`Confiner` 포트 및 `NoopConfiner`**:
   - `NoopConfiner.WrapCommand`는 `policy.RequireConfinement == true`이면 즉시 `domain.NewError(domain.ReasonConfinementUnavailable, "confinement", "kernel confinement is required but noop adapter is active", nil)`(`ExitInternalError = 16`)을 반환한다.
3. **AST 가드레일 (`TC-110-01`)**:
   - `internal/domain`, `internal/authn`, `internal/authz`, `internal/jail`, `internal/audit`이 `internal/confinement`를 import하면 즉시 테스트가 실패하도록 검증한다.

## 4. 인수 테스트 시나리오

| ID | 입력 | 기대 결과 |
|:---:|---|---|
| **TC-010-01** | 상대경로 또는 빈 경로가 포함된 `Policy.Validate()` 호출 | `*domain.Error`(`ReasonInvalidArguments`, `ExitBadInput = 14`) 반환 |

| **TC-010-04** | 코어 패키지에 `internal/confinement` import 구문 주입 시 `TC-110-01` 실행 | 가드레일 위반 즉시 검출 |
