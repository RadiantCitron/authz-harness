## 1. 목적 및 배경

승인 필요 작업의 미승인 차단(`Exit 18`), `ask` 후 승인 발급 시 동일 토큰 재시도 성공 및 2회차 승인 재사용(Replay) 차단(`Exit 18`), 타 리소스·타 토큰(`jti`) 승인 도용 차단, 만료된 승인 차단, 승인 발급 후 Grant 회수 시 즉시 거부(`Exit 12`)를 검증하는 G14 그룹 6대 시나리오(`E2E-67`~`E2E-72`)를 카탈로그에 편입한다.

## 3. 신규 시나리오 명세 (`G14`: PDP 승인 결정 `ask`)

| ID | 시나리오명 | 입력 조건 | 기대 Exit | 기대 감사 사유 (`Reason`) | 핵심 검증 증거 |
|:---:|---|---|:---:|---|---|
| `E2E-67` | 승인 필수(`RequiresApproval`) 작업 미승인 시 `ask` 차단 | `RequiresApproval: true` 쓰기 Grant + 승인 없음 | `18` | `APPROVAL_REQUIRED` | 파일 0바이트 무변화, 감사 `decision: "ask"` 기록 |
| `E2E-68` | 바인딩 승인 발급 후 1차 실행 성공 및 2회차 승인 재사용 차단 | 다회성 토큰(`MaxCalls: 2`)에 1회용 `approval grant` 발급 후 1차 실행(성공 `0`) → 동일 토큰으로 2차 실행 | `18` | `APPROVAL_REQUIRED` | 1차에서 승인이 원자 소비(`Consumed: true`)된 후 2차 호출이 `Gate 1`을 통과하더라도 `Gate 2/PEP`에서 `18`로 즉시 차단됨을 증명 |
| `E2E-69` | 다른 리소스 또는 다른 액션에 대한 승인 도용 차단 | `plan.txt` 승인만 받은 상태에서 `secret.txt` 쓰기 시도 | `18` | `APPROVAL_MISMATCH` | 리소스 바인딩 불일치 차단, 파일 무변화 |
| `E2E-70` | 다른 토큰(`jti`)으로 기존 승인 도용 차단 | 토큰 A(`jti-1`)에 발급된 승인을 토큰 B(`jti-2`)로 사용 시도 | `18` | `APPROVAL_MISMATCH` | `TokenJTI` 바인딩 불일치 차단 |
| `E2E-71` | TTL이 만료된 승인 사용 차단 | 승인 발급(TTL 1분) 후 가상 시계(`ClockOffset: 2*time.Minute`) 전진하여 호출 | `18` | `APPROVAL_EXPIRED` | `pdp.Request.Now` 기반 만료 승인 즉시 거부 |
| `E2E-72` | 승인 발급 후 기반 Grant 회수 시 승인 우회 차단 | 유효 승인 발급 직후 `grant revoke` 수행 → 실행 시도 | `12` | `GRANT_REVOKED` | 승인이 있어도 Grant 회수 시 `12`(`ExitAuthzDenied`)로 즉시 거부 |
