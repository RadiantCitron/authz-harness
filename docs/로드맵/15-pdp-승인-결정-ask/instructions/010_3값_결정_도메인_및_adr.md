## 1. 목적 및 배경

고위험 작업에 대해 자동 허용도 무조건 거부도 아닌 **사람 승인 요청(ask)**을 표현할 도메인 모델을 정의한다. 승인 바인딩·만료 판정 규칙은 **이 단계의 순수 함수 하나**로만 정의하고, PDP(030)와 소비 경로(020·040)가 그대로 재사용한다(024 A-5).
또한 종료 코드 `18`이 프로세스 경계를 건너 손실 없이 전달되도록 스포너·MCP·UI 매핑을 함께 고친다. 지금은 부모 스포너가 자식의 18을 16(`SUBPROCESS_ABNORMAL_EXIT`)으로 바꾼다([`termination.go`](../../../../internal/orchestrator/termination.go) 31행, 024 A-1).

## 3. 세부 명세

1. **모델**:
   ```go
   type Approval struct {
       ID        string    `json:"id"`
       Subject   string    `json:"subject"`
       Action    Action    `json:"action"`
       Resource  string    `json:"resource"`
       TokenJTI  string    `json:"token_jti"`
       ArgHash   string    `json:"arg_hash,omitempty"` // 비면 인자 바인딩 없음
       CreatedAt time.Time `json:"created_at"`
       ExpiresAt time.Time `json:"expires_at"`
   }
   type ApprovalBinding struct { Subject string; Action Action; Resource string; TokenJTI string; ArgHash string }
   ```
   `Consumed` 필드는 없다. 소비는 원장에서 지우는 것이다(024 결정 3).
2. **`(a Approval) Matches(b ApprovalBinding, now time.Time) Reason`**:
   - `Subject`·`Action`·`Resource`·`TokenJTI` 중 하나라도 다르거나, `a.ArgHash != "" && a.ArgHash != b.ArgHash`이면 → `ReasonApprovalMismatch`.
   - 바인딩은 맞지만 `!now.Before(a.ExpiresAt)`(`now >= ExpiresAt`)이면 → `ReasonApprovalExpired`.
   - 모두 통과하면 → `ReasonAuthorized`.
3. **`SelectApproval(approvals []Approval, b ApprovalBinding, now time.Time) (id string, reason Reason)`** (PDP·소비 공통 단일 원천):
   - `Matches == AUTHORIZED`인 승인이 있으면 첫 번째의 `ID`와 `ReasonAuthorized`.
   - 없으면 `b.Subject`와 같은 주체의 승인 중에서 `EXPIRED`가 하나라도 있으면 `ReasonApprovalExpired`, 그렇지 않고 `MISMATCH`가 있으면 `ReasonApprovalMismatch`.
   - 그 외(같은 주체의 승인이 없음)이면 `ReasonApprovalRequired`. 이 세 경우 `id`는 `""`다.
4. **`ValidateApprovalTTL(ttl time.Duration) (time.Duration, error)`**: `0`이면 `DefaultApprovalTTL(5m)`을 돌려준다. `ttl < 0` 또는 `ttl > MaxApprovalTTL(1h)`이면 `ReasonInvalidArguments` 오류(14)다.
5. **`ValidateArgHash(s string) error`**: `""`(바인딩 없음)이거나 `domain.DataDigest`와 같은 형식(`sha256:` + 소문자 hex 64자)만 허용한다. 그 밖은 `ReasonInvalidArguments`. 빈 페이로드는 `DataDigest`가 `""`를 내므로 인자 바인딩을 걸 수 없다(문서화된 한계).
