## 1. 목적 및 배경

민감한 파일 쓰기 등 고위험 작업에 대해 자동 허용도 무조건 거부도 아닌 **사람 승인 요청(`DecisionAsk = "ask"`)**을 내릴 수 있도록 PDP 3값 결정 도메인 모델을 정의한다.
본 단계에서는 `ROADMAP.md` §8의 미결 3건을 확정하는 **ADR 0005(`docs/adr/0005-pdp-3값-결정-및-일회성-승인-바인딩.md`)**를 작성하고, 종료 코드 `ExitApprovalRequired = 18` 및 사유 상수 3종(`APPROVAL_REQUIRED`, `APPROVAL_EXPIRED`, `APPROVAL_MISMATCH`), `Grant.RequiresApproval` 필드, `ApprovalRecord` 도메인 모델을 정의한다.

## 3. 세부 명세

1. **4요소 엄격 바인딩 (`Approval.Matches(sub string, action Action, resource string, jti string, now time.Time) (bool, Reason)`)**:
   - `Consumed == true`이면 거부(`ReasonApprovalRequired`).
   - `now.Unix() >= ExpiresAt`이면 거부(`ReasonApprovalExpired`).
   - `Subject != sub || Action != action || Resource != resource || TokenJTI != jti` 중 하나라도 다르면 거부(`ReasonApprovalMismatch`).
2. **종료 코드 매핑**:
   - `ReasonApprovalRequired`, `ReasonApprovalExpired`, `ReasonApprovalMismatch`는 모두 `ExitCodeForReason`에서 `ExitApprovalRequired(18)`로 매핑한다.
