## 1. 목적 (Context & Why)

본 지시서는 Phase 0부터 Phase 6까지 구축된 **Go 언어 기반 로컬 권한 검증 및 테스트 하네스(`authz-harness`)의 5계층 테스트 피라미드(L1~L5)를 최종 전수 실행하여 무결성을 증명**하고, 독립 바이너리 빌드(`bin/authz-harness`), 전체 로드맵 색인 및 대시보드를 최종 `Done` 상태로 완결하며, 프로젝트 전체 결산 문서(`결과정리및리뷰.md`)를 작성하는 최종 마감 작업이다.

보안 및 엔지니어링 불변식에 따라:
1. **5계층(L1~L5) 테스트 피라미드 완주 증명 (Full-Spectrum Verification)**:
   - **L1 (Deterministic Unit Tests)**: 클레임 파싱, Scope 부분집합, 순수 PDP 결정표 단위 테스트 무결성.
   - **L2 (Security Fuzzing & Edge Cases)**: Workspace Jail 경로 탈출, 토큰 헤더 변조 등 경계값 안전성.
   - **L3 (Concurrency & Virtual Clock)**: `-race` 감지기 기반 동시성 데이터 경합 0건 및 가상 시계 시간 제어.
   - **L4 (Black-Box CLI Contract)**: 컴파일된 독립 바이너리의 표준 종료 코드(`0`, `11`~`16`) 및 삼분 채널 격리.
   - **L5 (Full E2E Scenario Harness)**: 7대 그룹 30개 공격 시나리오 4중 검증(Quad-Assertion) 100% 통과 (1초 이내 초고속 완주).
2. **독립 바이너리 클린 빌드 (Clean Binary Compilation)**:
   - `go build -o bin/authz-harness ./cmd/authz-harness`로 독립 실행 가능한 단일 바이너리를 생성하고 직접 실행하여 라이프사이클을 검증한다.
3. **전체 로드맵 거버넌스 마감 (Roadmap Governance Closure)**:
   - `docs/로드맵/06-포트폴리오-패키징-및-문서화/README.md` 대시보드 상태를 `Done`으로 전이한다.
   - 상위 색인인 `docs/로드맵/README.md` 및 최상위 `ROADMAP.md`의 Phase 00부터 Phase 06까지 모든 단계를 `Done`으로 일괄 동기화한다.
4. **불변의 최종 결산 리뷰 (`결과정리및리뷰.md`) 작성**:
   - `ROADMAP_정책.md` §0 작업 흐름 5단계(마감) 규칙에 따라 Phase 06 및 프로젝트 전체 성과, 아키텍처 회고, 교훈을 집약한 불변의 결산 리뷰 문서를 작성한다.

## 2. 검증 범위 및 5계층 피라미드 설계

```text
       [ L5: Full E2E Scenarios ]      --> authz-harness run --scenario all (30/30 PASS, Quad-Assertion)
      [ L4: Black-Box CLI Contract ]   --> compiled binary, Exit Codes 0, 11~16, Stdout/Stderr/Audit
     [ L3: Concurrency & Clock ]       --> go test -race ./..., simulated clock, TOCTOU zero-race
    [ L2: Security Fuzzing & Bounds ]  --> filepath jail bounds, token malformed fuzzing
   [ L1: Deterministic Unit Tests ]    --> table-driven tests for PDP, exchange, keys, tokens
```

| 층위 | 테스트 항목 및 도구 | 완료 기준 |
|:---:|---|---|
| **L1** | 테이블 주도 단위 테스트 (`go test ./internal/...`) | 단위 로직 및 결정표 100% 통과, 1초 이내 완료 |
| **L2** | Jail 탈출 및 토큰 파싱 경계값 테스트 | 패닉 0건, Jail 외부 디렉터리 접근 차단 100% |
| **L3** | 동시성 경합 검증 (`go test -race ./...`) | Data Race 0건, TOCTOU 경합 방어 성공 |
| **L4** | 독립 바이너리 빌드 및 CLI 계약 | `go build -o bin/authz-harness ./cmd/authz-harness` 성공, 종료 코드 일치 |
| **L5** | 30대 시나리오 자동 판정 하네스 | 30개 시나리오 전수 `PASS`, 소요 시간 1초 미만, Quad-Assertion 4중 충족 |
