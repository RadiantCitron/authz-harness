## 1. 목적
Go 1.27 단일 모듈을 초기화하고, Zero Leakage(비밀값·개인정보 유출 원천 차단)를 강제하는 Git 무시 규칙, Gitleaks 설정 및 로컬 Pre-commit Hook 스크립트를 배치한다.

## 2. 작업 내역 및 산출물
1. `go.mod`: `module authz-harness`, `go 1.27`
2. `.gitignore`: Go 빌드 바이너리(`bin/`), 테스트 캐시, Workspace 임시 파일, 비밀키(`*.pem`, `*.key`, `.env*`)
3. `.gitleaks.toml`: 커밋 전 시크릿 탐지 규칙
4. `scripts/public_safety_scan.py`: 커밋 및 레포 내 비밀값/시크릿 안전 검사기
5. `scripts/githooks/pre-commit`: 커밋 전 자동 실행 훅 (`core.hooksPath` 연동)

## 3. 사전 인수 테스트 시나리오
- **시나리오 1**: `go env GOMOD` 실행 시 유효한 `go.mod` 파일 경로 반환.
- **시나리오 2**: 임의의 `.env` 파일 생성 시 `git status`에서 Untracked 파일로 잡히지 않고 무시됨.
- **시나리오 3**: `python3 scripts/public_safety_scan.py --all` 실행 시 오류 없이 정상 통과(Exit Code 0).
- **시나리오 4**: `gitleaks detect --no-git --verbose` 실행 시 리크 감지 없음.
