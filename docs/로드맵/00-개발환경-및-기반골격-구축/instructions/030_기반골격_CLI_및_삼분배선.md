## 1. 목적
Go 애플리케이션 진입점 `cmd/authz-harness/main.go`를 구현하고, 운영 로그(`slog`), CLI 출력(`stdout`), 감사 기록기(`internal/audit.Writer`)의 출력 삼분(Tri-Separation) 배선 골격을 수립하여 빌드 및 스모크 테스트를 통과시킨다.

---

## 2. 작업 내역 및 산출물
1. `cmd/authz-harness/main.go`: 플래그 파싱(`--version`, `--help`), 로거 초기화, 감사 기록기 호출 기본 흐름
2. `internal/audit/audit.go`: `Event` 구조체 스키마 정의 및 Append-only JSONL 기록기 (`Writer`)
3. `internal/audit/audit_test.go`: 감사 이벤트 직렬화 및 파일 기록 단위 테스트
4. `internal/cli/cli.go`: CLI 콘솔 메시지 포매터 (인간 대면 전용 출력)

---

## 3. 사전 인수 테스트 시나리오
- **시나리오 1**: `go test -v ./internal/audit/...` 실행 시 모든 단위 테스트 통과 (100% Pass).
- **시나리오 2**: `go build -o bin/authz-harness ./cmd/authz-harness` 빌드 성공.
- **시나리오 3**: `./bin/authz-harness --version` 실행 시 버전 정보 출력 및 프로세스 종료 코드 `0`.
- **시나리오 4**: 감사 이벤트 기록 시 지정된 `audit.jsonl`에 유효한 JSON 형식으로 1줄씩 추가되며, `stdout`이나 `stderr`로 출력 내용이 오염되지 않음.
