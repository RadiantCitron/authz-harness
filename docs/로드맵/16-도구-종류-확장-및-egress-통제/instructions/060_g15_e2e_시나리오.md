## 1. 목적 및 배경

루프백 Allow-List `net:fetch` 정상 호출, SSRF/URL 정규화 우회(`userinfo @`, 정수 IP, 비허용 포트, 리다이렉트) 차단, Allow-List `exec:run` 정상 실행, 미등록 바이너리 및 인자 주입 차단, 출력/시간 한계(로드맵 10) 작동, 그리고 `netguard`를 우회해 직접 소켓을 여는 악의 워커에 대한 OS 커널 격리(로드맵 11) 대조군 차단을 검증하는 G15 그룹 6대 시나리오(`E2E-73`~`E2E-78`)를 구현한다.

## 3. 신규 시나리오 명세 (`G15`: 도구 종류 확장 및 Egress 통제)

| ID | 시나리오명 | 입력 조건 | 기대 Exit | 기대 감사 (`ExpectedAction` / `ExpectedDecision` / `ExpectedReason`) | 핵심 검증 증거 |
|:---:|---|---|:---:|---|---|
| `E2E-73` | 루프백 Allow-List `net:fetch` 정상 위임 실행 | `net:fetch:127.0.0.1:<port>` Grant·축소 토큰으로 로컬 테스트 서버 호출 | `0` | `pep.allow` / `allow` / `AUTHORIZED` | 응답 수신 성공, 감사에 정규화된 `host:port` 및 `result_hash` 기록 |
| `E2E-74` | URL 정규화 우회(`@` userinfo, 정수 IP, 비허용 포트) Egress 차단 | `http://127.0.0.1@evil`, `http://2130706433`, 비허용 포트로 `net:fetch` 시도 | `12` | `pep.deny` / `deny` / `EGRESS_DENIED` | 소켓 연결 0건, `pep.deny` 감사 기록 |
| `E2E-75` | 외부 리다이렉트(`302 Found`) 응답 즉시 차단 | 로컬 서버가 외부 주소로 `302` 리다이렉트 반환 시 `net:fetch` 실행 | `12` | `pep.deny` / `deny` / `EGRESS_DENIED` | 리다이렉트 추종 0건, 응답 데이터 비노출 |
| `E2E-76` | Allow-List `exec:run` 정상 실행 및 미등록 ID·인자 주입 차단 | 허용 ID 정상 실행(`0`) 후 미등록 ID 및 `;` 메타문자 인자 주입 시도 | `12` | `pep.deny` / `deny` / `EXEC_ARG_REJECTED` (또는 `EXEC_NOT_ALLOWED`) | 비인가 프로세스 생성 0건, Workspace 무변화 |
| `E2E-77` | `net:fetch` / `exec:run` 실행 중 출력 폭주·타임아웃 자원 한계 차단 | 상한을 초과하는 대량 응답을 반환하는 로컬 엔드포인트 호출 (로드맵 10 연동) | `17` | `agent.limit_exceeded` / `deny` / `RESOURCE_OUTPUT_LIMIT` | 로드맵 10의 바이트 상한(`ReasonResourceOutputLimit`)이 신규 도구에도 동일하게 강제됨 증명 |
| `E2E-78` | `netguard` 우회 직접 소켓 연결 시도에 대한 OS 커널 격리 쌍 대조 차단 | 악의 워커가 PEP/`netguard`를 건너뛰고 비허용 소켓 연결 시도 (로드맵 11 연동) | `13` | `agent.confined` / `deny` / `CONFINEMENT_VIOLATION` | 격리 끔(대조군)에서는 연결 성공, 격리 켬(실험군)에서는 커널 차단 |

> **서브프로세스 역순 스캔 가림(`ORCHESTRATE_COLLECT`) 방지 및 상수 정합성 규약 ([013번 보고서](../../../보고서/013-5대_표준공학검증기법_기반_잔여로드맵_전수정밀진단_및_교정_보고서.md) `DEF-01`, `DEF-03`)**: 모든 시나리오는 위 표의 `ExpectedAction`(`pep.allow`, `pep.deny`, `agent.exit`, `agent.confined`)을 명시하여 `ORCHESTRATE_COLLECT` 가림 현상을 방지하며, `E2E-77`의 사유 코드는 로드맵 10 [`010`](../../10-서브프로세스-자원-및-수명-통제/instructions/010_자원_한계_도메인_모델_및_테스트_전용_워커.md)의 정본 상수인 `domain.ReasonResourceOutputLimit`(`"RESOURCE_OUTPUT_LIMIT"`)를 사용한다.
