## 1. 목적 및 배경

MCP 어댑터(`internal/mcp`)의 도구 화이트리스트를 `file_read`, `file_write`, `net_fetch`, `exec_run` 4종으로 늘린다. 어댑터는 여전히 소켓·프로세스를 직접 열지 않고 `SubprocessSpawner` → `subagent worker` 경로로만 집행한다(ADR 0001 A-5 유지). 워커가 `net:fetch`를 허용하려면 allow-list가 필요하므로, `mcp serve`가 받은 `-net-allow`를 워커 스폰 인자로 그대로 넘긴다(025번 T-13).

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - [`internal/mcp/protocol.go`](../../../../internal/mcp/protocol.go): `ToolNetFetch = "net_fetch"` → `domain.ActionNetFetch`, `ToolExecRun = "exec_run"` → `domain.ActionExecRun`. `ParseToolCallParams`를 **도구별 인자 구조체**로 나눈다(지금은 `path`·`data` 공용 구조체 하나).
  - `tools/list` 응답(도구 정의가 있는 파일): 4종, 각 `inputSchema`에 `additionalProperties: false`.
  - [`internal/cli/mcp.go`](../../../../internal/cli/mcp.go)(138행 `childArgs`): `-net-allow` 플래그를 받아 비어 있지 않으면 `childArgs`에 `"-net-allow", 값`을 덧붙인다.
  - [`internal/harness/architecture_test.go`](../../../../internal/harness/architecture_test.go) `TC-090-01`: 금지 목록에 `"net"`, `"net/http"`, `"os/exec"`, `"authz-harness/internal/netguard"`, `"authz-harness/internal/execguard"` 추가(지금 `internal/mcp`는 이 중 어느 것도 import하지 않는다).
  - `internal/mcp/protocol_test.go`, `server_test.go`, `internal/cli/mcp_test.go` 갱신.
- **무영향**: `file_read`·`file_write` 스키마와 동작, `executor.go`의 `SubagentRequest{Action, FilePath, Data}` 변환(새 도구도 같은 두 필드로 매핑되므로 그대로 쓴다), 종료 코드 → JSON-RPC 오류 매핑(새 사유는 모두 12).

---

## 3. 세부 명세

1. **도구별 인자 (`DisallowUnknownFields`)**:
   - `file_read`: `{ "path": 비어 있지 않은 문자열 }` → `Path`
   - `file_write`: `{ "path": …, "data": 문자열 }` → `Path`, `Data`
   - `net_fetch`: `{ "url": 비어 있지 않은 문자열 }` → `Path = url`, `Data = ""`
   - `exec_run`: `{ "command_id": 비어 있지 않은 문자열, "arg": 선택 문자열 }` → `Path = command_id`, `Data = arg`
   - 다른 도구의 인자(예: `net_fetch`에 `path`)는 알 수 없는 필드이므로 `ErrUnexpectedArgument`(-32602)다. 어댑터는 URL·ID의 형식을 검사하지 않는다(그것은 PEP Gate 0·2c의 몫이며, 같은 검사를 두 곳에 두지 않는다).
2. **응답**: 성공 시 기존과 같이 워커 `Output`을 텍스트로 돌려준다(본문·표준 출력). 원시 토큰은 응답·로그에 남지 않는다(A-4 유지).
3. **가드**: `TC-090-01` 확장으로 어댑터가 네트워크·프로세스·가드 패키지를 직접 쓰지 못하게 한다.

## 4. 인수 테스트 시나리오

| ID | 입력 | 기대 결과 |
|:---:|---|---|
| **TC-050-01** | `tools/list` | 정확히 4종, 각 `required`·`additionalProperties: false` |
| **TC-050-02** | `net_fetch`에 `url` 누락 / `path` 전달, `exec_run`에 `command_id` 누락 / `cmd` 전달, 미등록 도구 `curl` | 전부 `-32602`, 스포너 호출 0회(대역 실행기로 계수) |
| **TC-050-03** | 대역 실행기로 `net_fetch`·`exec_run` 정상 호출 | 실행기가 받은 `SubagentRequest`가 `{net:fetch, url, ""}`·`{exec:run, command_id, arg}`. 응답 텍스트 = 대역 `Output` |
| **TC-050-04** | `mcp serve -net-allow 127.0.0.1:P` | 워커 스폰 인자에 `-net-allow 127.0.0.1:P` 포함. 플래그가 없으면 인자에 없음 |
| **TC-050-05** | `TestArchitectureGuardrails/TC-090-01` | PASS |
