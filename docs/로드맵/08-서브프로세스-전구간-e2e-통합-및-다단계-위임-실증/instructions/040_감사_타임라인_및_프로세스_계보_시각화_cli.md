## 1. 목적 및 배경

다중 프로세스 환경에서 부모, 중간 관리자, 자식 워커가 동일한 `TraceID`를 공유하며 기록한 감사 이벤트는 `audit.jsonl`에 한 줄씩 누적됩니다.
기계는 이를 쉽게 파싱하지만, 보안 감사관이나 외부 면접관은 복잡한 다단계 위임 및 실시간 차단 과정을 한눈에 파악하기 어렵습니다.
본 단계에서는 **`authz-harness audit timeline --trace-id <id>`** CLI 서브커맨드를 구현하여, 단일 TraceID에 속한 모든 감사 이벤트를 프로세스 계보 트리(`CallerID` → `AgentID`)와 시간순 파이프라인으로 아름답게 시각화해 주는 사용자 경험(UX)을 완성합니다.

- **변경 대상 컴포넌트**:

  - 읽기 전용(Read-Only) CLI 뷰어이므로 기존 인가 코어, PEP/PDP, 토큰 교환기 및 저장소 파일 시스템에 아무런 영향을 주지 않습니다.

## 3. 세부 구현 명세

### 3.1 CLI 명령어 인터페이스
```bash
# 특정 TraceID의 전체 다중 프로세스 감사 타임라인 시각화
authz-harness audit timeline --trace-id tr-multihop-01

# 최신 시나리오 실행의 감사 타임라인 시각화
authz-harness audit timeline --latest
```

## 4. 인수 테스트 시나리오 (Acceptance Tests)

| 시나리오 ID | 입력 조건 | 기대 결과 |
|:---:|---|---|
| **TC-040-01** | `authz-harness audit timeline --trace-id <valid-id>` | 프로세스 트리와 시계열 이벤트가 일목요연하게 `stdout`으로 출력되고 `ExitCode: 0` |
| **TC-040-02** | 존재하지 않는 `trace-id` 조회 시 | "no audit events found for trace ID" 에러 메시지와 함께 적절한 종료 코드 반환 |
| **TC-040-03** | 차단(DENY) 이벤트가 포함된 타임라인 조회 시 | 차단 관문(Gate 2), 실패 사유(`Reason`), 종료 코드(`11`~`15`)가 빨간색/강조 박스로 표시 |
