## 3. 세부 검증 및 마감 명세

### 3.1 32대 E2E 시나리오 전수 서브프로세스 완주 검증
```bash
# 기본 모드(subprocess)로 32대 시나리오 완주 검증
./bin/authz-harness run --scenario all

# In-Process 빠른 모드와의 교차 검증
./bin/authz-harness run --scenario all --execution-mode inproc
```
- 32개 모든 시나리오의 Exit Code, 파일 변경 0바이트(거부 시), 감사 이벤트 사유 코드, SHA-256 해시 체인 무결성이 `PASS`로 판정되어야 함.

### 3.2 AST 아키텍처 가드레일 전수 확인
- `TC-060-01`: PDP의 OS/파일 패키지 0% 참조 불변식.
- `TC-060-02`: Worker의 Zone A/B 직접 접근 금지 불변식.
- `TC-060-03`: Zero Leakage (토큰 원문 하드코딩 및 정규식 누출 0건).
- `TC-060-04`: PEP `Execute`의 단일 출구(`return finalize(...)`) 수렴 불변식.
- **신규 가드레일 `TC-080-01`**: Control Plane 내부 `_ = audit.Log(...)` 0건 검증.
