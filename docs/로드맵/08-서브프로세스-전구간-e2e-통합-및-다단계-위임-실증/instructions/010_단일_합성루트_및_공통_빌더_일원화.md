## 1. 목적 및 배경

현재 `cli/pep.go`, `cli/subagent.go`, `cli/orchestrate.go`, `cli/token.go`, `catalog/helpers.go` 등 5곳 이상에 `KeyManager`·`Verifier`·`StateStore`·`PDP`·`PEP`·`AuditWriter`를 생성하고 초기화하는 의존성 조립 코드가 중복되어 있습니다.
또한 `internal/orchestrator/spawner.go`, `internal/authn/exchange/service.go`, `internal/authn/keys/manager.go` 내부에 `_ = Audit.Log(...)` 형태로 감사 기록 에러를 무시하는 구절이 남아 있어, 엄격한 Fail-Closed 감사 철학에 어긋납니다.
본 단계에서는 **단일 합성 루트(`internal/app/builder.go`)**와 **제네릭 원자적 파일 저장소(`internal/storage/atomic.go`)**를 구축하여 스택 조립을 일원화하고, 감사 에러 전파를 무결하게 정돈합니다.

## 3. 세부 구현 명세

### 3.1 제네릭 원자적 파일 저장소 (`internal/storage/atomic.go`)
- `type AtomicFileStore[T any] struct`:
  - `Read() (*T, error)`: `syscall.Flock(LOCK_SH)` 공유 잠금 후 JSON 디코딩.
  - `Write(data *T) error`: `syscall.Flock(LOCK_EX)` 배타적 잠금 후 동일 디렉터리 내 임시 파일 생성(`os.CreateTemp`), `json.MarshalIndent`, 동기화(`Sync`), 그리고 원자적 교체(`os.Rename`).

### 3.2 단일 합성 루트 (`internal/app/builder.go`)
- `type AppConfig struct`: 파일 경로들(`StatePath`, `PrivKeyPath`, `PubJWKSPath`, `ReplayPath`, `AuditPath`, `WorkspaceDir`), 시계(`Clock`), 로거(`Logger`).
- `type AppStack struct`: `StateStore`, `KeyManager`, `TokenIssuer`, `TokenVerifier`, `ClientReg`, `ReplayLedger`, `PAP`, `PIP`, `PDP`, `Jail`, `PEP`, `AuditWriter`.
- `func BuildStack(cfg AppConfig) (*AppStack, error)`: 단일 입구에서 전체 컴포넌트 의존성 주입 조립.
- `func (s *AppStack) Close() error`: `AuditWriter` 등 I/O 리소스 파일 디스크립터 안전 닫기 보장.

### 3.3 Control Plane 감사 에러 전파 정규화
- `spawner.go`: `s.cfg.Audit.Log(ev)` 실패 시 프로세스 스폰을 중단하고 `domain.ExitAuditFailure` 에러를 반환.
- `exchange/service.go`: 감사 기록 실패 시 `domain.ExitAuditFailure`를 반환하여 인가 원장에 반영되지 않은 토큰 교환을 차단.
