## 1. 목적 및 배경

`010`과 `030`에서 완성한 **순수 도메인(`domain`) 및 결정 코어(`pdp`)의 전이적(Transitive) 인프라 무의존성**과 **CLI의 단일 합성 루트(`internal/app`) 일원화 및 워커 CLI 경계 격리**가 영구히 깨지지 않도록 [`internal/harness/architecture_test.go`](../../../../internal/harness/architecture_test.go)에 정적 아키텍처 적합성 테스트(`TC-170-01`, `TC-170-02`)와 변이 검출 시험(`TC-170-03`)을 추가하여 아키텍처 가드레일 체계를 완성한다.

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/harness/architecture_test.go`:
    - **`TC-170-01` (전이적 의존성 0% 검증)**:
      - `internal/` 아래 모든 패키지의 프로덕션 `.go` 파일(`*_test.go` 제외)을 `go/parser`로 파싱하여 패키지별 직접 import 맵(`pkgImports map[string][]string`)을 만든다.
      - 시작 패키지(`authz-harness/internal/domain`, `authz-harness/internal/authz/pdp`)로부터 `authz-harness/internal/...` 내부 간선을 따라 DFS/BFS로 재귀 순회하면서, 시작 패키지 자신과 도달 가능한 모든 `internal/` 패키지가 import한 경로들을 수집한다(※ Go 표준 라이브러리 내부의 `time → os`를 따라가지 않고 우리 레포지토리의 `internal/` 패키지 그래프만 순회하므로 오탐이 없다 — [026번 보고서](../../../보고서/026-17번로드맵_구조결함_및_진행가능성_검증보고서.md) `D17-02`).
      - 수집된 도달 가능 import 집합에 다음 금지 패키지가 단 하나라도 있으면 즉시 실패한다:
        - 내부 패키지: `authz-harness/internal/storage`, `authz-harness/internal/authz/state`, `authz-harness/internal/authz/pip`, `authz-harness/internal/audit`, `authz-harness/internal/audit/checkpoint`, `authz-harness/internal/jail`, `authz-harness/internal/netguard`, `authz-harness/internal/execguard`, `authz-harness/internal/confinement`
        - 표준 라이브러리: `"os"`, `"syscall"`, `"os/exec"`, `"net"`, `"net/http"`, `"path/filepath"`, `"io/fs"`
    - **`TC-170-02` (CLI 단일 합성 루트 일원화 및 워커 CLI 경계 검증)**:
      - `internal/cli/` 내 프로덕션 `.go` 파일(`*_test.go` 제외)의 AST를 검사하여 다음 직접 생성 호출이 0건임을 검증한다:
        - `state.NewFileStore`, `keys.NewFileStore`, `token.NewFileReplayLedger`, `budget.NewFileLedger`, `audit.NewJSONLWriter`, `exchange.NewExchangeService`
      - 또한 `internal/cli/subagent.go`가 `"authz-harness/internal/authz/state"`를 import하지 않음을 검증한다.
    - **`TC-170-03` (가드 변이 검출 단위 시험 — 동어반복/False-Pass 방지)**:
      - 가짜 패키지 그래프(`pdp → pip → state → storage → os`)와 가짜 CLI AST(`state.NewFileStore(...)`, `audit.NewJSONLWriter(...)`)를 헬퍼 함수에 주입했을 때 `TC-170-01` 및 `TC-170-02` 검사 헬퍼가 정확히 위반을 검출(비어 있지 않은 위반 슬라이스 반환)하는지 검증한다.
- **무영향**:
  - 테스트 전용 파일 수정이므로 프로덕션 바이너리에 영향 없음.
