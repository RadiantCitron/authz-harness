## 1. 목적 및 배경

`010`~`030`에서 완성한 **순수 도메인(`domain`) 및 결정 코어(`pdp`)의 전이적(Transitive) 인프라 무의존성**과 **CLI의 단일 합성 루트(`internal/app`) 일원화**가 영구히 깨지지 않도록 [`internal/harness/architecture_test.go`](../../../../internal/harness/architecture_test.go)에 2개의 정적 아키텍처 적합성 테스트(`TC-170-01`, `TC-170-02`)를 추가하여 총 11대 가드레일 체계를 완성한다.

---

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/harness/architecture_test.go`:
    - `TC-170-01`: `internal/` 전체 패키지의 AST import 그래프를 재귀 순회(DFS/BFS)하여 `internal/domain`과 `internal/authz/pdp`의 **전이적(Transitive) import 집합**에 `internal/storage`, `internal/authz/state`, `internal/authz/pip`, `internal/audit`, `internal/jail`, `internal/netguard`, `internal/execguard`, `internal/confine`, `"os"`, `"syscall"`, `"os/exec"`, `"net"`, `"net/http"`가 단 하나도 포함되지 않음을 검증
    - `TC-170-02`: `internal/cli/` 내 프로덕션 `.go` 파일이 `state.NewFileStore`, `state.NewFileApprovalStore`, `keys.NewFileStore`, `token.NewFileReplayLedger`, `budget.NewFileLedger`를 직접 호출하지 않고 `internal/app.BuildStack` 단일 합성 루트를 사용함을 검증
- **무영향**:
  - 테스트 전용 파일 수정이므로 프로덕션 바이너리에 영향 없음.
