## 1. 목적 및 배경

Phase 16에서 통합된 3종 도구 가드(`jail`, `netguard`, `execguard`)와 실행 로직을 소비자 소유 전략 포트 인터페이스(`pep.ToolHandler`)로 깔끔하게 추상화한다.
특히 로드맵 16 [`040 지시서`](../../16-도구-종류-확장-및-egress-통제/instructions/040_pep_도구_디스패처_통합.md)에서 확립한 **`net:fetch`의 Gate 2(PDP) 이전 URL→`host:port` 정규화 순서**와 **`file:*` / `exec:run`의 Gate 2(PDP) 이후 Gate 2c 경계 검증 순서**를 3단 생명주기 메서드(`NormalizeResource`, `ValidateBoundary`, `ExecuteIO`)로 정형화하여, [`internal/authz/pep/gateway.go`](../../../../internal/authz/pep/gateway.go) 내부에서 액션별 `switch` 분기를 완전히 제거한다.

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/authz/pep/handler.go` [신규]: `ToolHandler` 인터페이스 및 기본 전략 구현체(`FileReadHandler`, `FileWriteHandler`, `NetFetchHandler`, `ExecRunHandler`) 정의
  - `internal/authz/pep/gateway.go`: `handlers map[domain.Action]ToolHandler` 레지스트리를 통해 Gate 2 직전 정규화(`NormalizeResource`), Gate 2c 경계 검사(`ValidateBoundary`), Stage 5 실행(`ExecuteIO`)을 단일 인터페이스로 호출(`TC-060-04` 단일 `return` 유지)
- **무영향**:
  - 기존 `pep.Config{Jail: ..., NetGuard: ..., ExecGuard: ...}`로 생성해도 `NewGateway` 내부에서 기본 `ToolHandler` 맵으로 자동 등록되므로 기존 호출부는 100% 호환된다.

## 3. 세부 명세

1. **`ToolHandler` 3단 전략 인터페이스 (Phase 16 `040` 정합성 100% 보존)**:
   - `NormalizeResource(rawResource string) (pdpResource string, targetURI string, err error)`:
     - Gate 2(PDP)에서 토큰의 기본 액션 스코프 보유를 확인한 직후, Grant 및 3단 타겟 스코프 대조 전에 호출된다.
     - `file:read` / `file:write` / `exec:run`: `rawResource, rawResource, nil`을 그대로 반환하여 PDP가 원시 경로/명령 ID로 Grant를 먼저 검사하게 한다.
     - `net:fetch`: `netguard.ParseAndNormalizeTarget(rawResource)`를 실행해 URL 우회(`@` userinfo, 비허용 포트 등) 시 즉시 `ReasonEgressDenied(12)`를 반환하고, 정상 시 추출된 `hostPort`(`127.0.0.1:18080`)를 `pdpResource`로, 전체 URL을 `targetURI`로 반환한다.
   - `ValidateBoundary(targetURI string, data []byte) (safeTarget string, err error)`:
     - Gate 2c에서 호출된다 (`file:*`는 `jail.ResolvePath`, `exec:run`은 `execguard.ValidateRequest`, `net:fetch`는 `targetURI` 그대로 반환).
   - `ExecuteIO(ctx context.Context, safeTarget string, data []byte) (outData []byte, bytesRead int, bytesWrote int, err error)`:
     - Stage 5에서 호출되어 실제 파일 읽기/쓰기, 루프백 HTTP GET, 허용 바이너리 실행을 수행한다.
