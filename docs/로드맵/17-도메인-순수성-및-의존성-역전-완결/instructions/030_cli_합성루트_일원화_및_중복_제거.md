## 1. 목적 및 배경

현재 [`internal/cli/`](../../../../internal/cli/) 하위 러너들은 단일 합성 루트([`internal/app/builder.go`](../../../../internal/app/builder.go))를 두고도 다음과 같은 파편화·중복·경계 누수를 안고 있다:
1. **수동 저장소·감사 로거 조립 및 파일 디스크립터 누수**: [`grant.go`](../../../../internal/cli/grant.go), [`pdp.go`](../../../../internal/cli/pdp.go), [`keys.go`](../../../../internal/cli/keys.go), [`approval.go`](../../../../internal/cli/approval.go)가 `BuildStack`을 거치지 않고 각자 `state.NewFileStore`, `keys.NewFileStore`, `audit.NewJSONLWriter`를 직접 호출하며 `Close()`도 없다. [`orchestrate.go`](../../../../internal/cli/orchestrate.go)와 [`mcp.go`](../../../../internal/cli/mcp.go)도 `audit.NewJSONLWriter`를 직접 호출한다.
2. **`ExchangeService` 중복 생성**: [`token.go`](../../../../internal/cli/token.go)(41~50행, 308~317행)는 `BuildStack`이 이미 `stack.ExchangeService`를 조립해 주는데도 밖에서 `exchange.NewExchangeService`를 또 생성한다(게다가 수동 생성본에는 `WithBudgetLedger` 옵션이 빠져 있다).
3. **워커 CLI의 중앙 상태 패키지 직접 참조**: [`subagent.go`](../../../../internal/cli/subagent.go)(12, 108~115행)는 `BeforeIOHook`을 걸기 위해 `internal/authz/state`를 직접 import하여 `stack.StateStore.Update`를 호출한다.
4. **PEP CLI 플래그 파싱 루프 중복**: [`pep.go`](../../../../internal/cli/pep.go)의 `runRead`와 `runWrite` 사이에 위치 인자(`resource`)와 플래그를 분리하는 25줄 루프 및 `--clock-offset` 파싱 코드가 중복되어 있다.

본 단계에서는 `app.BuildStack`의 부분 경로 선택적 조립 조건을 정교화하여 전 CLI 러너를 `app.BuildStack`으로 100% 일원화하고 위 4가지 문제를 한 번에 해결한다.

## 2. 파급 범위와 무영향 근거

- **변경**:
  - `internal/app/builder.go`: 부분 경로만 주어진 경우에도 오류나 불필요한 파일 생성 없이 필요한 컴포넌트만 선택적으로 조립하도록 조건 분기 정교화 + `AppConfig.EnableRevokeBeforeIOHook bool` 옵션 추가 + 중복 초기 키 회전 블록 제거
  - `internal/cli/grant.go`, `internal/cli/pdp.go`, `internal/cli/keys.go`, `internal/cli/approval.go`: 수동 스토어·감사 로거 생성 제거 → `app.BuildStack` 및 `Close() error` 메서드 추가
  - `internal/cli/orchestrate.go`, `internal/cli/mcp.go`: `audit.NewJSONLWriter(auditFlag)` 직접 호출을 `app.BuildStack(app.AppConfig{AuditPath: auditFlag, VerifyOnly: true})` 및 `defer stack.Close()`로 전환
  - `internal/cli/token.go`: 중복 `exchange.NewExchangeService` 호출 제거 → `stack.ExchangeService`(및 `offsetStack.ExchangeService`) 직접 사용
  - `internal/cli/subagent.go`: `AppConfig{..., EnableRevokeBeforeIOHook: true}` 사용으로 `internal/authz/state` 및 `internal/authz/pep` import 완전 제거
  - `internal/cli/pep.go`: `runRead`·`runWrite` 공통 인자 분리 함수(`splitPEPResourceAndFlags`) 및 `parseNonNegativeClockOffset` 헬퍼 추출
  - `cmd/authz-harness/main.go`: `grant`, `approval`, `pdp`, `keys`, `token`, `pep` 러너 생성 직후 `defer ...Close()` 호출 추가
- **무영향**:
  - CLI 플래그, 표준 출력/에러 문구, 생성자 시그니처(`NewGrantRunner` 등), 종료 코드는 기존과 100% 동일하다.

## 3. 세부 명세 (누적 코드 가상 합성 검증 반영 — [026번 보고서](../../../보고서/026-17번로드맵_구조결함_및_진행가능성_검증보고서.md) `D17-01`, `D17-06`, `D17-07`)

### 3.1 `internal/app/builder.go` 부분 경로 선택적 조립 규칙 (필수 준수)

`grant`·`pdp`·`approval` CLI는 `StatePath`와 `AuditPath`만 넘기고(`PubJWKSPath == ""`, `ReplayPath == ""`), `keys` CLI는 `PrivKeyPath`·`PubJWKSPath`·`AuditPath`만 넘기며(`StatePath == ""`, `ReplayPath == ""`), `orchestrate`·`mcp` CLI는 `AuditPath`만 넘긴다. 따라서 `BuildStack`은 반드시 아래 5가지 조건식을 지켜야 한다:

1. **`AppConfig` 필드 추가**:
   ```go
   EnableRevokeBeforeIOHook bool // true: req.InjectRevokeBeforeIO 활성 시 I/O 직전 모든 Grant 회수 훅 장착
   ```
2. **빈 `ReplayPath`에서 현재 디렉터리(`"."`) 오염 방지**:
   - 기존 코드는 `if cfg.BudgetPath == ""`이면 무조건 `filepath.Join(filepath.Dir(cfg.ReplayPath), "budget_ledger.json")`을 실행하여 `ReplayPath == ""`일 때 현재 작업 디렉터리(`"."`)에 `budget_ledger.json`을 생성했다.
   - 반드시 **`if cfg.BudgetPath == "" && cfg.ReplayPath != ""`** 일 때만 파생하도록 수정한다.
3. **키 매니저(`KeyStore`, `KeyManager`) 선택적 조립 및 중복 회전 제거**:
   - **`if cfg.PubJWKSPath != ""`** 일 때만 `keys.NewFileStore`와 `keys.NewManager`를 생성한다 (`grant`·`pdp`·`approval`·`orchestrate`·`mcp`에서는 건너뛴다).
   - 또한 [`keys.NewManager`](../../../../internal/authn/keys/manager.go)(73~126행)는 이미 빈 키 링일 때 첫 번째 active 키 1개를 자동 생성(`key.created`)한다. 기존 `BuildStack` 128~141행의 `RotateKey` 블록은 불필요한 중복이므로 제거하여 `NewKeysRunner` 기존 동작(초기 active 키 1개)과 100% 일치시킨다.
4. **예산·리플레이·토큰(`BudgetLedger`, `ReplayLedger`, `TokenIssuer`, `TokenVerifier`, `ExchangeService`) 선택적 조립**:
   - **`if cfg.PubJWKSPath != "" && cfg.ReplayPath != ""`** 일 때만 `budget.NewFileLedger`, `token.NewFileReplayLedger`, `token.NewService`, `token.NewVerifier`, `exchange.NewExchangeService`(내부에서 `exchange.NewDownscopeValidator()` 기본 사용)를 조립한다.
   - 이 가드가 있어야 `keys` CLI(`ReplayPath == ""`)를 실행할 때 빈 경로 에러가 나지 않고 불필요한 원장 파일이 생기지 않는다.
5. **PEP 게이트웨이 조립 조건 및 `EnableRevokeBeforeIOHook` 캡슐화**:
   - 기존 `if pdpSvc != nil` 조건만으로는 `grant`·`pdp`·`approval` CLI에서 `tokenVerifier == nil` 및 `workspaceJail == nil` 상태로 `pep.NewGateway`가 호출되어 `pep: verifier is required` 에러가 발생한다!
   - 반드시 **`if pdpSvc != nil && tokenVerifier != nil && workspaceJail != nil`** 일 때만 `netguard.NewGuard`, `execguard.NewRunner`, `pep.NewGateway`를 조립한다.
   - 게이트웨이 생성 직후 `if cfg.EnableRevokeBeforeIOHook && stateStore != nil`이면:
     ```go
     pepGateway = pep.WithBeforeIOHook(pepGateway, func(ctx context.Context, req pep.Request) error {
         return stateStore.Update(func(st *state.GrantsState) error {
             for i := range st.Grants {
                 st.Grants[i].Status = domain.GrantStatusRevoked
             }
             return nil
         })
     })
     ```
     로 감싼다.

### 3.2 각 CLI 러너 전환 명세

- **`cli/grant.go` (`GrantRunner`) & `cli/approval.go` (`ApprovalRunner`)**:
  - `stack, err := app.BuildStack(app.AppConfig{StatePath: statePath, AuditPath: auditPath})`로 조립하고 `stack.PAP`를 사용한다.
  - `Close() error` 메서드를 추가하여 `r.stack.Close()`를 위임한다 (`internal/audit`, `internal/authz/state` import 제거).
- **`cli/pdp.go` (`PDPRunner`)**:
  - `stack, err := app.BuildStack(app.AppConfig{StatePath: statePath, AuditPath: auditPath, VerifyOnly: true})`로 조립하고 `stack.PDP`, `stack.PIP`를 사용한다.
  - `Close() error` 메서드를 추가한다 (`internal/audit`, `internal/authz/state` import 제거).
- **`cli/keys.go` (`KeysRunner`)**:
  - `stack, err := app.BuildStack(app.AppConfig{PrivKeyPath: privPath, PubJWKSPath: pubPath, AuditPath: auditPath})`로 조립하고 `stack.KeyManager`를 사용한다.
  - `Close() error` 메서드를 추가한다 (`internal/audit` import 제거; `keys.ErrKeyNotFound` 에러 비교를 위해 `internal/authn/keys` import는 유지).
- **`cli/token.go` (`TokenRunner`)**:
  - `NewTokenRunner`와 `runExchange`에서 수동으로 호출하던 `exchange.NewExchangeService(...)`를 제거하고 `stack.ExchangeService`와 `offsetStack.ExchangeService`를 그대로 사용한다.
- **`cli/orchestrate.go` & `cli/mcp.go`**:
  - `audit.NewJSONLWriter(auditFlag)` 대신 `stack, err := app.BuildStack(app.AppConfig{AuditPath: auditFlag, VerifyOnly: true})` + `defer stack.Close()`를 사용하고 `stack.AuditWriter`를 스포너에 주입한다 (`internal/audit` import 제거).
- **`cli/subagent.go` (`SubagentRunner`)**:
  - `app.BuildStack` 호출 시 `EnableRevokeBeforeIOHook: true`를 설정하고 `subagent.NewWorker(stack.PEP)`에 바로 전달하여, `cli/subagent.go`에서 `internal/authz/state` 및 `internal/authz/pep` import를 완전히 제거한다.
- **`cli/pep.go` (`PEPRunner`)**:
  - `runRead`와 `runWrite`에서 반복되는 위치 인자(`resource`)·플래그 분리 루프를 `splitPEPResourceAndFlags(args []string) (resource string, flagArgs []string)` 헬퍼로, `--clock-offset` 파싱 및 음수 거부를 `parseNonNegativeClockOffset(raw string) (time.Duration, error)` 헬퍼로 추출한다.
