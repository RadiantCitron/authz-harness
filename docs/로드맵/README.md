> **차기 로드맵 10~16 안내**: 설계 문서만 있고 구현지시서는 없다. 결정 기록은 [ADR 0003](../adr/0003-차기-로드맵-범위-개정-비목표-조건부-해제.md)(Proposed)와 [ADR 0002](../adr/0002-관측성-포트-분리-및-오픈텔레메트리-전환.md)(Proposed)다. 권장 순서는 10 → 11 → 12 → 13 → 14 → 15 → 16이며, 의존 관계는 각 로드맵 `ROADMAP.md`의 선행 조건을 따른다. ADR이 `Accepted`가 되기 전에는 해당 로드맵의 코드 구현을 시작하지 않는다. 신규 시나리오 그룹은 G9(10번)~G15(16번)이며 번호는 직전 완료 로드맵의 마지막 시나리오 번호+1부터 부여한다. 신규 종료 코드는 `17`(10번), `18`(15번)이다.
