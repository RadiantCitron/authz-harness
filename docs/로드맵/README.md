## 0. 오랜 시간이 지난 뒤 복귀할 때를 위한 상황 파악 가이드 (Quick Resume Guide)

오랜 시간이 지난 뒤 이 프로젝트를 다시 열었을 때, **아래 4가지만 확인하면 단 3분 만에 전체 상황을 100% 파악하고 바로 이어서 진행**할 수 있습니다.

### 1) 이 프로젝트의 정체성 (절대 잊지 말아야 할 원칙)
- 본 프로그램(`authz-harness`)은 헤르메스나 오픈클로 같은 LLM 에이전트 애플리케이션이 **아닙니다**.
- 멀티·분산 에이전트 프로그램들이 공통으로 필요로 하는 **권한 축소 위임(AuthZ), 프로세스·커널 격리(Confinement), 실패-안전 감사 배선(Fail-Closed Audit Wiring)을 비결정적 LLM 없이 100% 결정론적으로 시뮬레이션하고 증명하는 코어 엔진 겸 아키텍처 학습 교보재**입니다([007번 보고서](../보고서/007-분산에이전트_권한감사_아키텍처_타당성_및_감사무결성_권한결합_보고서.md)).
- 따라서 **16번 로드맵까지만 보안·배선 검증 기능을 구현한 뒤 일체의 기능 추가를 동결(Feature Freeze)**하고, **17번(의존성 역전 DIP 완결 및 중복 제거)**과 **18번(7대 디자인 패턴 및 클린 아키텍처 코드리딩 교보재 편찬)**으로 마감합니다([008번 보고서](../보고서/008-로드맵16_완주이후_차기방향_및_클린아키텍처_DIP_모범정제_보고서.md)).
