## 1. 목적 및 배경

권한(Scope), 수명(TTL), 위임 깊이(Depth)에 이은 4번째 단조 축소 축으로 **호출 횟수·읽기 바이트·쓰기 바이트 예산(`domain.Budget`)**을 도입한다.
본 단계에서는 `ROADMAP.md` §8의 미결 4건을 확정하는 **예산 모델 ADR(`docs/adr/0004-예산-축소-위임-예약-및-정산-모델.md`)**을 수립하고, 순수 도메인 모델(`domain.Budget`), 토큰 클레임 필드(`TokenClaims.Budget`), 그리고 예산 거부 사유 2종(`ReasonBudgetExhausted`, `ReasonDelegationBudgetExceeded`)을 정의한다.

## 3. 세부 명세

### 3.1 ADR 0004 핵심 확정 사항 (구현 시 착오 방지)
1. **배분 및 회수 방식 (Reservation & Lazy Reclaim)**:
   - 자식 토큰 교환 시 부모의 현재 잔여 예산(`Remaining`)에서 자식의 요청 예산만큼 원자적으로 차감(예약)하고, 자식이 만료(`now >= child.ExpiresAt`)된 후 다음 원장 접근 시 미사용 잔여량을 부모에게 자동 반환(Lazy Reclaim)한다.
2. **`Initial` 상한과 `Remaining` 잔여량의 `0` 의미 분리 (핵심 함정 방어)**:
   - 만약 `Budget{MaxCalls: 3}`처럼 호출 횟수만 지정하고 `MaxReadBytes: 0, MaxWriteBytes: 0`으로 발급한 토큰에서 `0`을 "잔여 0바이트"로 해석하면 단 1바이트의 파일 읽기/쓰기도 불가능해진다. 반대로 `Remaining == 0`을 "무제한"으로 해석하면 `MaxWriteBytes: 20`을 다 써서 `0`이 되었을 때 무제한으로 풀리는 버그가 생긴다.
   - 따라서:
     - 모든 유효한 `Budget`은 **`MaxCalls > 0`이 필수**다 (`MaxCalls <= 0`이면 `Validate()` 실패).
     - `MaxReadBytes`와 `MaxWriteBytes`는 초기 발급값(`Initial.MaxReadBytes > 0`, `Initial.MaxWriteBytes > 0`)이 양수일 때만 해당 바이트 한도가 활성화된 것으로 판정한다 (`HasReadLimit() bool`, `HasWriteLimit() bool`).
     - 바이트 한도가 활성화된 경우(`Initial.MaxWriteBytes > 0`), 소비 후 `Remaining.MaxWriteBytes == 0`이 되면 "잔여 0바이트(소진됨)"로 판정하여 추가 쓰기를 차단한다.
3. **Gate 1 `ReplayLedger`(1회성 소비)와 `BudgetLedger`(다회성 예산)의 관계**:
   - 기존 [`verifier.go`](../../../../internal/authn/token/verifier.go) 225행은 모든 토큰을 Gate 1에서 `replayLedger.CheckAndConsume`으로 1회 소비 처리한다.
   - 토큰에 `claims.Budget != nil`이 설정된 경우에는 사용 횟수 통제 주체가 `BudgetLedger`(`MaxCalls`)이므로, Gate 1에서는 `replayLedger.CheckAndConsume`을 건너뛰고 Gate 2/PEP의 `BudgetLedger`가 횟수를 차감하도록 역할을 분리한다 (`claims.Budget == nil`인 기존 토큰은 기존 1회성 `replayLedger` 동작을 100% 유지하여 `E2E-18`을 보존한다).

### 3.2 `domain.Budget` 메서드 (`internal/domain/budget.go`)
- `Validate() error`: `MaxCalls <= 0 || MaxReadBytes < 0 || MaxWriteBytes < 0`이면 `domain.NewError(domain.ReasonInvalidArguments, "domain_budget", "...", nil)`(`ExitBadInput = 14`) 반환.
- `HasReadLimit() bool`: `b.MaxReadBytes > 0` 반환.
- `HasWriteLimit() bool`: `b.MaxWriteBytes > 0` 반환.
