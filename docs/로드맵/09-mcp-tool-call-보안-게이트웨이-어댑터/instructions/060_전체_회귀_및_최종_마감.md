## 3. 세부 명세
1. `go test -race ./...` 전체 실행.
2. `authz-harness run --scenario all`로 신규 포함 전체 시나리오 완주.
3. `audit verify`로 실행 후 해시 체인 검증.
4. AST 가드레일(`TC-060-01`~`04`, `TC-080-01`, `TC-090-01`) 전체 통과 확인.
5. 문서 동기화: 시나리오 수와 신규 명령(`mcp serve`)을 [최상위 README](../../../../README.md), [MASTER_ROADMAP](../../MASTER_ROADMAP.md), [로드맵 색인](../../README.md)에 반영.
6. 결산은 사용자 종료 선언 시에만 `결과정리및리뷰.md`로 작성한다.
